# Late Samples Monitor — releases

Download **LateSamplesMonitor.exe** from the
[latest release](../../releases/latest).

Each release is built and published automatically when a change is merged into
the (private) source repository. The program updates itself: every time it
starts, it checks this repository's latest release and, if it is newer,
downloads it, checks its SHA-256, and restarts into it.

This repository holds releases only — no source code.
